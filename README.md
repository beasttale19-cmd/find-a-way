# FIND A WAY - Story game

---

# Introduction

FInd a way is a fun story game where there is a detective character trying to escape from a haunted-like place. There are riddles on the way, pickable item to get clues etc.

---

# Pages

In Find a Way game there are multiple pages. They are:

- Main page - consists of which door to go: whether door 1 or door2.
- About page - consists of info of the game and the developer
- Door 1 - Consists the whole game story for now.
- Door 2 - Is currently under developement, it is not released yet.
